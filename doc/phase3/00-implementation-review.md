## 5. 首次审计验证证据（历史）

环境：本机 Windows/amd64；`go version` 为 go1.26.0，go.mod 要求 go1.26.0，x/sys v0.48.0。没有另建用户或修改网络配置来构造环境。

首次直接 `go test ./... -cover` 返回非零：测试包通过，但无测试包的覆盖率辅助编译报告 go1.26.0/go1.25.1 不匹配。将当前进程 PATH 的首项设为已选择工具链的 bin 后，完整命令退出 0。此为执行环境修正，不是修改全局 PATH 或项目代码。

可复现命令（Windows PowerShell，参数含 `=` 时整体加引号）：

```powershell
$diagGoRoot = go env GOROOT
$env:PATH = (Join-Path $diagGoRoot 'bin') + ';' + $env:PATH
go test ./... '-coverprofile=coverage-audit.out'
go tool cover '-func=coverage-audit.out'
go vet ./...
gofmt -l .
```

| 检查 | 本轮结果 |
| --- | --- |
| 完整测试 | 退出 0，全部包测试通过；main/version 为无测试包 |
| 整体语句覆盖率 | 87.3%（由完整 profile 汇总，含无测试包；非包百分比平均值） |
| app / cli / collect | 85.5% / 100.0% / 76.1% |
| detect / model / probe | 98.7% / 89.2% / 91.9% |
| report / ui / winapi | 92.9% / 95.7% / 73.2% |
| Classify | 100.0% 语句执行证据（Go coverage 不统计分支覆盖率）；不代表缺失证据组合逻辑已验收 |
| go vet | 退出 0，无问题 |
| gofmt | 无输出，无差异 |

collect 的包覆盖率不等于“纯函数覆盖率 ≥80%”验收值；后续需定义纯函数范围并单独统计。网络真机测试结果受当前网络和安全软件影响，不外推到其他机器。
