## 1. 阻塞项决策记录（Q1–Q5）

| 编号 | 决策问题 | **最终决策** | 决策理由 |
| --- | --- | --- | --- |
| Q1 | MVP 是否含 PRD 5.6 可选增强（启动项 / 磁盘占用分析） | **不含，顺延 V1.1** | 5.1–5.4 已是完整产品骨架；5.6 单独接近后半段量级，并入将挤压测试与工程化阶段。架构上预留采集器注册机制，保证 V1.1 扩展零改核心。 |
| Q2 | 报告默认写入位置 | **多级降级策略**：① `-o` 参数指定目录 → ② EXE 所在目录（可写则用） → ③ `%USERPROFILE%\Desktop-Diag\reports\` → ④ `%TEMP%`；报告头显式标注实际路径与降级原因 | 同时覆盖「共享目录只读」「断网共享不可达」「就地留档」三种真实场景，并把写入位置从隐式行为变为显式声明，规避合规争议 |
| Q3 | 采集技术路线 | **路线乙：纯 Win32 API + 只读注册表**，零 PowerShell / 零 WMI / 零 COM / 零脚本引擎 | 把「不易被 EDR 与组策略拦截」从宣传语变为**可验证的架构事实**（WMI 查询与 PowerShell 调用恰是 EDR 重点监控行为）。使 PRD D1 条目由「依赖 PowerShell」修订为「不调用任何脚本引擎」 |
| Q4 | 非管理员权限处理 | **MVP 即实现权限自适应**：启动检测管理员身份；单项失败在报告第二层标注「⚠ 因权限不足未采集（原因：X）」；第一层输出「诊断不完整」提示 | 静默缺数据会被误判为「系统正常」，与「减少漏判」的核心价值直接冲突 |
| Q5 | B 类未量化阈值 | **全部采用评审建议默认值**（见第 6 节），统一收敛为**配置常量**，便于后续调参 | 判定规则必须可编码、可单元测试，否则「智能判错」无法验证 |

## 2. 产品硬约束（不可变更的红线）

以下 7 条来自 PRD 3.3 / 第 4 节 / 5.5，任何设计、编码、迭代均不得突破：

| 编号 | 红线约束 |
| --- | --- |
| C-01 | **只读不写**：不得修改任何系统关键配置（注册表写入、IP/DNS/网卡配置、服务状态、启动项） |
| C-02 | **只诊不修**：不得自动执行任何修复、优化、清理动作 |
| C-03 | **零上传**：不得有任何后台上报、遥测、埋点行为；网络行为仅为面向公网可用性目标的无载荷连通性探测 |
| C-04 | **无驻留**：不得注册服务/计划任务/自启动，不得后台常驻，进程退出即完全结束 |
| C-05 | **无 GUI**：不得弹窗、不得创建窗口；全部交互为控制台文本 |
| C-06 | **无脚本引擎**：不调用 `powershell.exe`、`wscript.exe`、`cscript.exe`、`cmd.exe /c` 等（Q3 决策强化） |
| C-07 | **无外部依赖**：交付物为单个 EXE，运行时无 DLL/运行库/安装包依赖，无需安装 |

**允许的写操作白名单（唯一例外）**：仅可写入本产品自身的诊断报告文件与控制台标准输出/标准错误。

## 4. 功能性需求与验收标准（E1 补齐）

> 验收标准均为**可判定**：给定输入场景 → 期望可观测输出。

### 4.1 M1 系统与网络信息采集

| ID | 需求 | 验收标准 |
| --- | --- | --- |
| REQ-F-101 | 采集计算机名 | 报告中出现计算机名，且与 `hostname` 输出一致 |
| REQ-F-102 | 采集操作系统版本与内部版本号 | 报告出现如 `Windows 11 Pro for Workstations (10.0.26200)`；版本号取自 `RtlGetVersion`（非 `GetVersionEx`，后者在 Win8.1+ 存在版本谎报） |
| REQ-F-103 | 采集系统运行时长 | 报告出现「X 天 Y 小时 Z 分」，取值自 `GetTickCount64`；与实际开机时间误差 < 5 分钟 |
| REQ-F-104 | 枚举全部网卡（含已禁用） | 每块网卡输出：名称、描述、MAC、状态（已连接/已断开/已禁用）、是否虚拟网卡 |
| REQ-F-105 | 每块活动网卡输出 IPv4 地址与子网掩码 | 与 `ipconfig` 输出一致；无 IPv4 时显式输出「无 IPv4 地址」而非空白 |
| REQ-F-106 | 每块活动网卡输出默认网关 | 与 `ipconfig` 一致；无网关时显式输出「未配置」 |
| REQ-F-107 | 每块活动网卡输出 DNS 服务器列表 | 与 `ipconfig /all` 一致；无 DNS 时显式输出「未配置」 |
| REQ-F-108 | 输出 IPv6 概况（地址数量与是否仅有链路本地地址） | 报告出现 IPv6 地址与「仅链路本地」标记 |
| REQ-F-109 | 采集结果结构化（非原生命令文本） | 报告第二层为字段化表格/键值对，不出现 `ipconfig` 原始排版；原生命令原始文本仅允许出现在第三层附录 |

### 4.2 M2 网络连通性探测

| ID | 需求 | 验收标准 |
| --- | --- | --- |
| REQ-F-201 | 对每块「已连接且有默认网关」的网卡分别执行网关 ICMP 探测 | 报告按网卡分组给出丢包率、最小/平均/最大延迟 |

## 5. 采集技术实现口径（Q3 决策落地）

| 采集项 | 实现方式 | 备注 |
| --- | --- | --- |
| 计算机名 | `GetComputerNameExW` | Win32 |
| OS 版本 | `RtlGetVersion`（ntdll） | 规避 `GetVersionEx` 版本谎报 |
| 系统运行时长 | `GetTickCount64` | Win32 |
| 网卡列表 / IP / 掩码 / MAC / 状态 / 网关 / IPv6 | `GetAdaptersAddresses`（IP Helper API） | 单次调用取全量，含 `FirstGatewayAddress` |
| DNS 服务器列表 | 只读注册表 `HKLM\SYSTEM\CurrentControlSet\Services\Tcpip\Parameters\Interfaces\{GUID}` 的 `NameServer` / `DhcpNameServer` | 与活动网卡按 GUID 关联 |
| 静态 IP / 掩码兜底校验 | 同上注册表键 `IPAddress` / `SubnetMask` | 仅校验，不作主来源 |
| CPU 占用率 | `GetSystemTimes` 两次采样求差 | 1s 窗口 |
| 内存 | `GlobalMemoryStatusEx` | 总量/可用/占用率 |
| 系统盘容量 | `GetDiskFreeSpaceExW` | 盘符取 `%SystemDrive%` |
| 虚拟网卡识别 | 适配器 `IfType` + 描述关键字（VMware/VirtualBox/Hyper-V/TAP/WireGuard 等） | 用于报告标注与探测对象过滤 |

**依赖约束**：唯一允许的第三方模块为 `golang.org/x/sys`（Go 官方扩展库）；其余一律标准库。构建时 `CGO_ENABLED=0`、`-trimpath`。

## 6. 判定规则基线（Q5 决策落地 · 全部量化为配置常量）

### 6.1 告警等级

| 等级 | 标记 | 含义 |
| --- | --- | --- |
| SEVERE | `[严重]` | 直接导致功能不可用，需立即处理 |
| WARNING | `[警告]` | 潜在风险或性能劣化，建议排查 |
| — | 正常项 | 不计入告警，仅出现在第二层详情 |

### 6.2 规则表

| 规则 ID | 触发条件 | 等级 | 告警文案（第一层） |
| --- | --- | --- | --- |
| R-01 | IPv4 地址以 `169.254.` 开头 | SEVERE | DHCP 地址获取失败，终端未获取有效内网 IP |
| R-02 | 活动网卡默认网关为空/未配置 | SEVERE | 无网关配置，内网出口异常，无法正常联网 |
| R-03 | 活动网卡 DNS 列表为空 | SEVERE | DNS 未配置，局域网域名与网页均无法正常解析 |
| R-04 | DNS 仅含 `0.0.0.0` 或仅含 `127.0.0.1` | SEVERE | DNS 配置异常（指向无效地址），域名解析将失败 |
| R-05 | 仅有 IPv6 链路本地地址（`fe80::/10`）且无全局 IPv6 地址，同时无有效 IPv4 | WARNING | 网络未获得有效 IP（仅链路本地地址），无法对外通信 |
| R-06 | 内存占用率 ≥ 95% | SEVERE | 系统内存严重过载，存在程序闪退与系统卡死风险 |
| R-07 | 内存占用率 ≥ 85% 且 < 95% | WARNING | 系统内存占用偏高，终端运行可能卡顿 |
| R-08 | CPU 占用率 ≥ 95% | SEVERE | CPU 持续满载，系统响应严重迟缓 |
| R-09 | CPU 占用率 ≥ 85% 且 < 95% | WARNING | CPU 占用率偏高，存在系统卡顿风险 |
| R-10 | 系统盘剩余空间 < 10 GB 且 ≥ 5 GB | WARNING | 系统盘空间不足，存在系统卡顿、更新失败风险 |
| R-11 | 系统盘剩余空间 < 5 GB | SEVERE | 系统盘空间严重不足，存在系统异常与更新失败高风险 |
| R-12 | 网关 ICMP 丢包率 ≥ 20%（未达 100%） | WARNING | 内网链路存在丢包，网络稳定性异常 |
| R-13 | 网关 ICMP 平均延迟 ≥ 150 ms | WARNING | 内网延迟偏高，访问内网资源缓慢 |
| R-14 | 网关 ICMP 丢包率 = 100% | SEVERE | 无法连通网关，内网链路中断 |
| R-15 | 系统 DNS 解析失败，但直连 223.5.5.5 解析成功 | SEVERE | 本机 DNS 服务不可用，网页无法正常访问（外网链路正常） |
| R-16 | 直连 223.5.5.5 解析也失败 | SEVERE | DNS 解析能力完全不可用，外网访问中断 |
| R-17 | 公网 TCP 443 全部目标连接失败（且网关可达） | SEVERE | 外网访问中断（内网链路正常），疑似出口或防火墙策略问题 |
| R-18 | 网关不可达但公网 TCP 443 可达 | WARNING | 网关探测异常但外网可达，疑似 ICMP 被防火墙拦截（非真实故障） |
| R-19 | 任一采集项失败/未采集 | WARNING | 诊断不完整，N 项数据缺失，结论可能不完整（清单见第二层） |

### 6.3 故障层级判定矩阵（REQ-F-205）

| 网关 ICMP | 系统 DNS | 直连 223.5.5.5 DNS | TCP 443 | 结论 |
| --- | --- | --- | --- | --- |
| 通 | 成功 | 成功 | 成功 | 内网正常 · 外网正常 |
| 通 | 失败 | 成功 | 成功 | 内网正常 · 外网正常，**本机 DNS 故障** |
| 通 | 失败 | 失败 | 失败 | 内网正常 · **外网异常** |
| 通 | 成功 | 成功 | 失败 | 内网正常 · **外网端口受限**（疑似策略拦截） |
| 不通 | — | — | 失败 | **内网链路异常** |
| 不通 | — | — | 成功 | 内网探测异常（疑似 ICMP 被拦截），外网可达 |
| 无网关可探测 | — | — | — | 无法判定（配合 R-02） |

**阈值集中管理**：以上所有数值必须在代码中定义为具名常量（集中于单一配置文件/包），不得散落魔法数字。

## 8. 边界与异常场景清单（E3 补齐 · 必须定义期望行为）

| 场景 | 期望行为 |
| --- | --- |
| S-01 无任何网卡 | 不崩溃；报告标注「未检测到网络适配器」；M2 全部探测跳过并计入 R-19 |
| S-02 全部网卡被禁用 | 同上，且状态标注为「已禁用」 |
| S-03 仅有无线且未连接 | 网关探测跳过；提示「无线未连接」；不计入内网断连严重级 |
| S-04 多网卡（有线+无线+VPN）同时活动 | 过滤物理活动网卡逐块探测；虚拟网卡标注为虚拟并排除出探测对象 |
| S-05 仅 IPv6、无 IPv4 | 触发 R-05；M2 按 IPv6 网关探测（若实现成本高则标注「MVP 仅诊断 IPv4 链路」并计入 R-19） |
| S-06 静态 IP 且未配置网关 | 触发 R-02 |
| S-07 系统盘非 C 盘 | 按 `%SystemDrive%` 正确识别，不硬编码 C |
| S-08 非管理员账户运行 | 完整跑完；报告头标注「管理员：否」；权限受限项按 R-19 标注 |
| S-09 磁盘剩余空间为 0 或极小 | 正常采集并触发 R-11；报告写入自动降级到可写目录 |
| S-10 从只读共享目录运行 | 报告降级写入用户目录，报告头注明降级原因 |
| S-11 断网环境运行 | 程序可启动并完成本地采集；网络探测全部失败并给出「全断网」结论（这正是产品价值场景） |
| S-12 中文/空格/超长路径 | 报告路径正常、文件正常写入 |
| S-13 虚拟机环境 | 正常采集；虚拟网卡正确识别标注 |
| S-14 系统时间异常（影响报告文件名） | 使用系统时间但报告头同时记录原始时间戳；文件名冲突时追加序号 |
| S-15 连续运行同一分钟/秒 | 文件名不覆盖（追加序号），旧报告不删除 |
| S-16 代理环境（配置了 IE/系统代理） | TCP 443 探测走**直连**（不走系统代理），避免代理导致的误判；报告注明直连语义 |
| S-17 目标终端注册表 Tcpip 接口键不可读 | DNS 回退显示「未采集」并计入 R-19，不误报 R-03 |
| S-18 CPU 采样窗口内系统空闲 | 正常输出低占用率，不误报 |

## 9. CLI 契约

```
Desktop-Diag.exe [选项]

选项：
  -o <目录>      指定报告输出目录（优先级最高；目录不存在则尝试创建，失败则降级）
  -v             详细模式：输出各采集项原始返回值、数据来源、耗时（用于排障）
  -version       打印版本、构建提交、构建时间后退出
  -h, --help     打印帮助与合规声明后退出

退出码：
  0   诊断完成，无严重告警
  1   诊断完成，存在严重告警
  2   程序自身错误（无法生成报告等）

交互：全流程无任何输入等待、无图形弹窗，纯文本输出。
```

**设计说明**：MVP 不引入子命令体系；`--json`、`--no-color`、`--timeout` 等列入 V1.1。
