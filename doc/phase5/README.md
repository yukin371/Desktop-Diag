## 工作约束

- 构建和测试脚本只修改当前进程的环境变量，不写入用户或系统级配置。
- CI 失败必须通过原始退出码传递，不能用输出文本推断成功。
- 交叉编译结果只能证明编译成功，不能替代对应 Windows/架构真机验收。
- 发布脚本只生成 EXE、校验文件和必要的构建元数据，不上传、不创建 Git tag。
